# Security Policy

## About This Project

This repository contains intentionally malicious code published for security research, malware analysis, and educational purposes.

Because the project may contain potentially harmful functionality, researchers should exercise appropriate caution when analyzing or executing it.

## Safe Research

Only perform testing on systems that you own or have explicit authorization to test.

Researchers should use an isolated laboratory environment and should avoid:

* Testing against third-party systems
* Accessing unauthorized data
* Using real credentials
* Connecting the sample to infrastructure that is not under their control
* Deploying the software on production systems

## Responsible Disclosure

Security research should be performed only with appropriate authorization.

Do not use vulnerabilities or functionality contained in this project to gain unauthorized access to systems, obtain data, deploy ransomware, disrupt services, or otherwise cause harm.

## Scope

This policy covers security issues affecting this repository, its source code, documentation, build process, and associated development infrastructure.

It does not grant permission to test the software against systems that you do not own or have explicit authorization to test.

## Legal Notice

This security policy does not provide authorization to perform security testing against third-party systems.

Users are responsible for complying with all applicable laws, regulations, contracts, and authorization requirements.
