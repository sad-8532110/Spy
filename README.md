# Spy

> ⚠️ **SECURITY RESEARCH / EDUCATIONAL PROJECT**

This repository contains intentionally malicious software developed for **security research, malware analysis, detection engineering, and educational purposes**.

The project may contain functionality associated with backdoor and ransomware behavior. It is intended to help researchers and students understand malicious behavior and develop defensive security techniques.

## ⚠️ Warning

**Do NOT run this software:**

* On production systems
* On systems you do not own
* On systems for which you do not have explicit authorization
* On systems containing important or irreplaceable data
* Against third-party networks or services

Testing should only be performed in an **isolated laboratory environment** using systems and data specifically created for testing.

## Laboratory Safety

If you choose to study this project, use an isolated and controlled environment.

Recommended precautions include:

* Use a dedicated virtual machine
* Keep the laboratory isolated from production networks
* Use synthetic or disposable test data
* Do not use real credentials or sensitive information
* Take snapshots before testing
* Avoid connecting the sample to infrastructure you do not control
